# Парсер логов access.log

Скрипт анализирует access.log и собирает:
- Общее количество запросов
- Кол-во запросов по методам (GET, POST и т.д.)
- Топ-3 IP по кол-ву запросов
- Топ-3 самых долгих запроса

## Как использовать

### Один лог-файл:
```bash
python parse_logs.py logs/access.log
